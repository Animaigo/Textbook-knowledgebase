# 把知识库放在这里

本目录下**每本书一个子目录**，结构固定为：

```
kb/
└── 书名/
    ├── 00-使用说明与版本信息.md
    ├── 原文索引.md
    ├── _连字修正白名单.txt
    └── 原文/          ← 抽取出来的逐字原文（唯一事实来源）
```

## 怎么建

```bash
# 先诊断（不落盘），判读规则见根目录《新书入库核对清单.md》
python tools/pdf2kb.py probe "你的书.pdf"

# 核对通过后抽取。--out 必须落在 kb/<书名>/原文
python tools/pdf2kb.py extract "你的书.pdf" --out "kb/书名/原文" --tidy

# 重建索引
python tools/kb_index.py --kb "kb/书名"
```

## 为什么要有这个结构

`cite_check.py` 就放在 `tools/` 下，而 `kb/` 是它的**兄弟目录**。
脚本从这个固定相对位置推出库在哪，所以：

- **解压 / clone 到任何盘、任何目录都能直接跑，不必传 `--kb`**
- `kb/` 下有多本时会报错并列出候选，不会静默猜一本

只要不破坏 `kb/<书名>/原文/` 这个结构，位置随便放。

## 注意

- `原文/` 是脚本产物，**不要手工编辑** —— 重跑会被覆盖，也会破坏「逐字保真」的可验证性。
- 本目录下的一切内容都已被 `.gitignore` 排除，不会误传到公开仓库。
